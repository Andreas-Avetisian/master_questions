# Cloud: Name the three major cloud service models and which one do you choose for what? Advantages/disadvantages?

## Three major cloud service models

The three major cloud service models are **SaaS**, **PaaS**, and **IaaS**. They mainly differ in how much the provider manages for you and how much control remains with you.

## SaaS: Software as a Service

**SaaS** means delivery of ready-to-use business applications over the internet.

Examples: Microsoft Office 365, Google Workspace, web-based CRM or ticketing tools.

Choose SaaS when:

- you need a standard application quickly
- customization and deep technical control are not the main concern
- you want the provider to manage almost everything
- end users should only need a browser or client app

Main advantage: lowest operational effort for the customer. The provider manages the application, platform, operating system, infrastructure, updates and much of the security.

Main disadvantage: lowest control. You depend strongly on the provider's features, data handling, availability, and terms.

## PaaS: Platform as a Service

**PaaS** means delivery of a solution stack for developing and running applications.

Examples: Azure App Service, Google Cloud Platform services, managed databases, application runtimes.

Choose PaaS when:

- you develop your own application
- you want to focus on code and data
- you do not want to manage servers, operating systems, runtime installation, or many deployment details
- fast development and deployment matter more than low-level control

Main advantage: good compromise between productivity and control. Developers can build and deploy quickly while the provider manages infrastructure, OS, runtime, and tools.

Main disadvantage: possible platform lock-in. Your application may depend on provider-specific services and APIs.

## IaaS: Infrastructure as a Service

**IaaS** means delivery of raw computing resources such as virtual machines, disk space, object storage, firewalls, and network connectivity.

Examples: AWS EC2, Azure Compute, cloud VMs and storage.

Choose IaaS when:

- you need more technical control
- you want to migrate existing server-based systems
- you have special OS, middleware, network, or security requirements
- you are willing to manage operating systems, runtimes, applications, and data yourself

Main advantage: most flexibility and control among the three models.

Main disadvantage: more operational responsibility remains with the customer.

## General cloud advantages

Cloud computing is attractive because of common cloud properties:

- **On-demand use**: services can be turned on and off as needed.
- **Elasticity / scalability**: resources can be added or removed dynamically.
- **Self-service**: standardized offerings can be configured without long negotiations.
- **Multi-tenancy**: provider infrastructure is shared across customers, lowering cost.
- **Abstraction**: the customer gets an outcome as a service without managing every layer.
- **Pay-as-you-go**: costs depend on actual usage and shift from CAPEX to OPEX.
- **Economies of scale**: large providers can run data centers efficiently.
- **Fast experimentation**: it is cheaper to try, measure, and iterate.

## General disadvantages and risks

Important disadvantages are:

- **Loss of exclusive control**: you cannot fully see how the provider operates internally.
- **Provider dependency**: outages, discontinued services, price changes, or API changes affect you.
- **Internet dependency**: access to cloud systems depends on network connectivity.
- **Misconfiguration risk**: self-service can lead to wrong access rights or leaked data buckets.
- **Multi-tenancy risk**: providers must separate customers, but bugs and hardware vulnerabilities can still happen.
- **Legal and data concerns**: data ownership, data-center location, and contractual promises matter.
- **Dynamic environment**: cloud services change quickly, so keeping up can be stressful.
- **Shared responsibility**: security responsibility depends on whether you use IaaS, PaaS, or SaaS.

## Short summary

Use **SaaS** for standard ready-made applications, **PaaS** for developing and deploying your own code without server management, and **IaaS** when you need raw infrastructure and more control. The higher the abstraction, the less you manage, but the less control you have. Cloud advantages are scalability, self-service, pay-per-use, abstraction, and fast experimentation. Disadvantages are dependency, reduced control, legal/security risks, misconfiguration, outages, and lock-in.
